# app-volume

맥 메뉴바에서 프로그램별 볼륨을 조절하는 작은 믹서입니다.

## 동작

- 오디오를 연 프로그램을 앱 단위로 묶어 슬라이더로 보여 줍니다. 크롬처럼 도우미 프로세스가 여럿이어도 한 줄입니다.
- 슬라이더를 100% 미만으로 내린 앱에만 프로세스 탭을 겁니다. 100%인 앱은 건드리지 않아 지연이 없습니다.
- 음소거 버튼을 누르면 게이지가 0으로 내려가고, 풀면 이전 값으로 돌아옵니다.
- 값은 앱 이름으로 저장되어 앱을 다시 켜도 따라갑니다.
- 오디오 드라이버를 설치하지 않습니다. 맥의 Core Audio 프로세스 탭을 씁니다.

## 요구 사항

- macOS 14.2 이상
- 스위프트 컴파일러(Xcode 또는 명령줄 도구)
- 처음 실행할 때 오디오 캡처 권한을 허용해야 합니다.

## 빌드와 실행

```
./build.sh
./mixer
```

목록만 확인하려면 `./mixer --list` 를 실행합니다.

## 알려진 한계

- 탭은 만들 때의 기본 출력 장치에 붙습니다. 출력 장치를 바꾸면 믹서를 다시 켜야 합니다.
- 블루투스 기기에서 지연이나 끊김이 생길 수 있습니다. 충분히 확인하지 못했습니다.
- 저작권 보호가 걸린 앱은 소리가 잡히지 않을 수 있습니다.
- 한 번도 오디오를 연 적 없는 프로그램은 목록에 나타나지 않습니다.
