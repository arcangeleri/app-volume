# app-volume

맥 메뉴바에서 프로그램별 볼륨을 조절하는 작은 믹서입니다.

## 동작

- 오디오를 연 프로그램을 앱 단위로 묶어 슬라이더로 보여 줍니다. 크롬처럼 도우미 프로세스가 여럿이어도 한 줄입니다.
- 슬라이더를 100% 미만으로 내린 앱에만 프로세스 탭을 겁니다. 100%인 앱은 건드리지 않아 지연이 없습니다.
- 음소거 버튼을 누르면 게이지가 0으로 내려가고, 풀면 이전 값으로 돌아옵니다.
- 값은 앱 이름으로 저장되어 앱을 다시 켜도 따라갑니다.
- 오디오 드라이버를 설치하지 않습니다. 맥의 Core Audio 프로세스 탭을 씁니다.

## 요구 사항

- macOS 14.2 이상
  - 프로세스 탭을 만드는 함수가 14.2부터 제공되는 것은 SDK 헤더로 확인했습니다.
  - 프로세스 목록 조회 항목은 헤더에 버전 표시가 없어 확인하지 못했습니다.
  - 실제로 돌려 본 환경은 macOS 26 한 대뿐입니다.
- 스위프트 컴파일러. Xcode 또는 명령줄 도구를 설치하면 들어 있습니다.
  - 명령줄 도구만 설치하려면 `xcode-select --install` 을 실행합니다.

## 빌드

저장소를 받고 빌드 스크립트를 실행합니다.

```
git clone https://github.com/arcangeleri/app-volume.git
cd app-volume
./build.sh
```

- 같은 폴더에 `mixer` 실행 파일과 `app-volume.app` 앱 폴더가 생깁니다.
- `Info.plist` 에 오디오 캡처 권한 안내 문구와 메뉴바 전용 설정(독에 안 뜸)이 들어 있습니다.
- 앱 폴더에는 임시 서명을 합니다. 권한이 이 앱 하나에 붙게 하려는 것입니다.
- 실행 권한이 없다는 메시지가 나오면 `chmod +x build.sh` 를 먼저 실행합니다.

## 설치와 자동 실행

앱 폴더를 응용 프로그램 폴더로 복사해서 쓰면 로그인할 때 자동으로 켜 둘 수 있습니다.

```
cp -R app-volume.app ~/Applications/
open ~/Applications/app-volume.app
```

- 메뉴바 아이콘을 눌러 「로그인할 때 자동 실행」을 누르면 켜지고, 다시 누르면 꺼집니다. 켜져 있으면 체크 표시가 붙습니다.
- 시스템 설정의 일반 → 로그인 항목에서도 확인하고 끌 수 있습니다.
- 앱 폴더를 다른 곳으로 옮기거나 지우면 등록이 풀릴 수 있습니다. 옮긴 뒤에는 메뉴에서 다시 확인합니다.
- 등록과 상태 확인은 명령으로도 됩니다. 앱 폴더 안의 실행 파일로 불러야 합니다.

```
~/Applications/app-volume.app/Contents/MacOS/mixer --login on
~/Applications/app-volume.app/Contents/MacOS/mixer --login off
~/Applications/app-volume.app/Contents/MacOS/mixer --login status
```

- 로그인 때 실제로 켜지는지는 재로그인으로 확인하지 못했습니다. 등록 상태가 「등록됨」으로 나오는 것까지만 확인했습니다.

## 실행

터미널에서 실행합니다.

```
./mixer
```

- 메뉴바에 막대가 쌓인 모양의 아이콘이 생깁니다. 독에는 나타나지 않습니다.
- 터미널 창을 닫아도 계속 두려면 백그라운드로 실행합니다.

```
nohup ./mixer > /dev/null 2>&1 &
```

### 처음 실행할 때

- 오디오 캡처 권한을 묻는 창이 뜨면 허용합니다.
- 제 환경에서는 권한 창 없이 동작했습니다. 권한 창이 어떤 조건에서 뜨는지는 확인하지 못했습니다.
- 소리가 줄지 않으면 시스템 설정의 개인정보 보호 및 보안에서 실행한 터미널 앱의 오디오 관련 권한을 확인합니다.

## 사용법

1. 소리를 내는 프로그램을 켭니다. 한 번도 소리를 낸 적 없는 프로그램은 목록에 나타나지 않습니다.
2. 메뉴바 아이콘을 누릅니다.
3. 목록에서 앱의 슬라이더를 움직여 볼륨을 조절합니다. 오른쪽에 현재 퍼센트가 보입니다.
4. 오른쪽 스피커 버튼을 누르면 음소거됩니다. 게이지가 0으로 내려가고 퍼센트 자리에 「음소거」가 보입니다.
5. 다시 누르면 음소거 전 값으로 돌아옵니다.
6. 음소거 중에 슬라이더를 직접 움직이면 음소거가 풀리고 그 위치가 새 값이 됩니다.
7. 슬라이더를 100%로 올리면 그 앱에는 더 이상 탭이 걸리지 않습니다.

### 목록에 보이는 앱

- 독에 뜨는 일반 앱은 소리를 내지 않아도 오디오를 연 적이 있으면 보입니다.
- 시스템 데몬은 소리를 내고 있거나 볼륨을 낮춰 둔 때만 보입니다.
- 앱을 닫으면 목록에서 빠집니다. 저장된 볼륨은 남아 있어서 다시 켜면 같은 값이 적용됩니다.

### 목록만 확인하기

실행하지 않고 오디오를 연 프로세스 목록만 출력하려면 다음을 실행합니다.

```
./mixer --list
```

- 출력 한 줄에 프로세스 번호, 메뉴 표시 여부, 출력 중 여부, 묶음 이름이 나옵니다.
- 앱이 목록에 안 보이는 이유를 찾을 때 씁니다.

## 끝내기

- 메뉴의 「종료」를 누릅니다. 걸어 둔 탭이 정리되고 원래 소리로 돌아옵니다.
- 터미널에서 직접 끄려면 프로세스 번호를 찾아 종료 신호를 보냅니다.

```
kill <프로세스 번호>
```

- 비정상 종료 뒤에도 소리가 계속 줄어 있다면 해당 앱을 다시 켭니다. 이 경우를 충분히 확인하지는 못했습니다.

## 알려진 한계

- 탭은 만들 때의 기본 출력 장치에 붙습니다. 출력 장치를 바꾸면 믹서를 다시 켜야 합니다.
- 블루투스 기기에서 지연이나 끊김이 생길 수 있습니다. 충분히 확인하지 못했습니다.
- 저작권 보호가 걸린 앱은 소리가 잡히지 않을 수 있습니다.
- 한 번도 오디오를 연 적 없는 프로그램은 목록에 나타나지 않습니다.
- 임시 서명이라 다른 맥으로 옮겨 쓰면 처음 실행할 때 보안 경고가 뜰 수 있습니다. 직접 빌드해서 쓰는 것을 전제로 합니다.
